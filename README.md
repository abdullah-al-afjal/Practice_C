## What is C Language?
C is a procedural, general-purpose programming language developed by Dennis Ritchie in 1972 at Bell Labs.It is fast, powerful, and often used for system/software development, embedded systems, operating systems (like Linux), and low-level programming.

###  1. Data Types
Basic types: int, float, char, double  
Derived types: arrays, pointers, structures  

### 2.Operators
Arithmetic: +, -, *, /, %  
Relational: ==, !=, <, >, <=, >=  
Logical: &&, ||, !  
Assignment: =, +=, -=, etc.  

### 3. Control Statements
if, if-else: Conditional branching  
switch-case: Multi-way branching   
Loops: for, while, do-while for repetition  

### 4.File Handling
Working with files: fopen(), fclose(), fread(), fwrite(), etc.

### 5.Dynamic Memory Allocation
Use functions: malloc(), calloc(), realloc(), free()

### 6.Header Files
Standard libraries like:  
stdio.h – input/output  
stdlib.h – standard utilities  
string.h – string handling  
math.h – math functions
